# HñaHñu

Prototipo de un juego didáctico en Godot ambientado en el Valle del Mezquital, orientado al aprendizaje de palabras en hñähñu.

## Abrir el proyecto

1. Instalar Godot 4.7 o una versión compatible con el proyecto.
2. Importar el archivo `project.godot` en Godot.
3. Ejecutar con F5. La escena inicial es Pueblo.

## Controles

- Pueblo: flechas o WASD para explorar; Espacio para un salto corto.
- Cascadas: flechas izquierda/derecha y Espacio para saltar.

## Estado actual

- Pueblo con movimiento libre y límites verticales.
- Cascadas con movimiento de plataformas y derrota al caer al agua.
- Selector de niveles y puertas de cambio de escena.
- Mapa de laberinto en preparación.
- Juegos didácticos de formación de palabras pendientes de implementar.

La carpeta `.godot/` se genera localmente al importar el proyecto y no se incluye en el repositorio.
